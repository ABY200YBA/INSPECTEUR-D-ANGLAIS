# Inspecteur Coach iOS

Native iOS companion for INSPECTEUR - IEMS Anglais Sénégal.

## Features
- Structured IEMS coaching answers
- Voice dictation (Speech framework) and spoken answers
- Written-answer review grid
- Training pathway and PDF reference link

## Open in Xcode
1. Install XcodeGen on a Mac.
2. In this folder, run: xcodegen generate
3. Open InspecteurCoach.xcodeproj, select an iPhone simulator or device, then Run.

Minimum target: iOS 17. The app requests microphone and speech-recognition permissions only when the user taps Dictate.
